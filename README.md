Entry for the [make.fun](https://make.fun/bounty/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) competition "One Line, Zero Use: The Useless Superpower Sprint".

`main.py` (Python 3.13, pure standard library, deterministic, no network)
writes one original line (87 characters) to `entry.txt`: a superpower for
hearing houseplants think, spoiled by the fact that every one of them is
disappointed in you. A real, specific power that is completely worthless —
exactly what the brief asks for.

Run it with:

```sh
python3 main.py
```

It prints the character count (Unicode code points) and the SHA-256 of
`entry.txt`.
